# 🌐 Basic Frontend Projects

A collection of beginner frontend projects built with **HTML**, **CSS**, and **JavaScript** 

---

## 📁 Projects

### 1. 🌤️ Weather App
Search any city and get real-time weather data including temperature, humidity, and wind speed.
- **Tech:** HTML, CSS, JavaScript, OpenWeatherMap API
- **Features:** Live weather data, dynamic weather icons, error handling
- 🔗 [Live Demo](https://kp-weatherweb.netlify.app/)
---

### 2. ✅ To-Do List App
A clean and functional task manager to keep track of your daily tasks.
- **Tech:** HTML, CSS, JavaScript, LocalStorage
- **Features:** Add/delete tasks, mark as complete, data persists on refresh
- 🔗 [Live Demo](https://kp-todolist.netlify.app/)
---

### 3. ❓ Quiz App
A multiple-choice quiz app that tests your general knowledge.
- **Tech:** HTML, CSS, JavaScript
- **Features:** Score tracking, correct/incorrect highlighting, play again option
- 🔗 [Live Demo](https://kp-quizweb.netlify.app/)
---

### 4. 💬 Quote Generator
Fetches and displays a random inspirational quote with a tweet option.
- **Tech:** HTML, CSS, JavaScript, DummyJSON API
- **Features:** Random quotes on click, tweet directly to Twitter/X
- 🔗 [Live Demo](https://kp-quotegen.netlify.app/)
---

### 5. 📝 Notes App
Create, edit, and delete personal notes that are saved in the browser.
- **Tech:** HTML, CSS, JavaScript, LocalStorage
- **Features:** Create multiple notes, editable content, auto-save, delete notes
- 🔗 [Live Demo](https://kp-notesweb.netlify.app/)
---

### 6. 🎂 Age Calculator
Calculate your exact age in years, months, and days from your date of birth.
- **Tech:** HTML, CSS, JavaScript
- **Features:** Date picker, accurate age calculation, blocks future dates
- 🔗 [Live Demo](https://kp-agecal.netlify.app/)
---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Krish-Prasad09/Basic-Frontend-Projects.git
   ```
2. Navigate to any project folder (e.g., `P1` for Weather App)
3. Open `index.html` in your browser

> No installations or dependencies required — runs directly in the browser!
